🚀 Quick Start - 15 Minutes Setup

CodeCanyon Buyers: Follow these 4 steps to get your app ready for the App Store.

What You Need

  • Xcode 15.0+ (free from Mac App Store)
  • Apple Developer Account ($99/year)
  • AdMob Account (free from Google)

Step 1: Open Project (2 minutes)

1. Extract the downloaded ZIP file
2. Open CaptionCraft.xcodeproj in Xcode
3. Wait for project to load

Step 2: Configure Bundle ID (3 minutes)

  1. Select CaptionCraft project in navigator
  2. Select CaptionCraft target
  3. Go to "Signing & Capabilities" tab
  4. Change Bundle Identifier to: com.yourcompany.yourapp
  5. Select your Apple Developer team

Step 3: Test Build (5 minutes)

  1. Select iPhone simulator
  2. Press Cmd+R to build and run
  3. Test basic functionality
Success! If the app builds, continue to AdMob Setup.

Step 4: Next Steps

Click "2. AdMob Setup" in the sidebar to configure monetization.
