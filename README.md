## 🚀 **Quick Start (15 Minutes)**

### **Step 1: Open Project**
```bash
1. Extract ZIP file
2. Open CaptionCraft.xcodeproj in Xcode
3. Wait for project to load
```

### **Step 2: Configure Bundle ID**
```bash
1. Select CaptionCraft project
2. Go to Signing & Capabilities
3. Change Bundle ID: com.yourcompany.yourapp
4. Select your Apple Developer team
```

### **Step 3: Setup AdMob**
```bash
1. Create AdMob account at admob.google.com
2. Get your App ID and Ad Unit ID
3. Update Info.plist with App ID
4. Update Constants.swift with Ad Unit ID
```

### **Step 4: Test & Deploy**
```bash
1. Build and test on device
2. Verify ads load correctly
3. Submit to App Store
4. Start earning revenue! 🎉
```
