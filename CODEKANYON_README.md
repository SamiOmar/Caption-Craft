## 🚀 Quick Start (15 Minutes to App Store Ready)

### **Step 1: Configure App (5 minutes)**
```
1. Open CaptionCraft.xcodeproj in Xcode
2. Change Bundle ID to: com.yourcompany.yourapp
3. Select your Apple Developer team
4. Replace app icon with your design
5. Build and run to test
```

### **Step 2: Setup AdMob (10 minutes)**
```
1. Create AdMob account at admob.google.com
2. Create iOS app, get App ID
3. Create Rewarded ad unit, get Ad Unit ID
4. Update Info.plist with App ID
5. Update Constants.swift with Ad Unit ID
```

### **Step 3: App Store Submission**
```
1. Archive and upload to App Store Connect
2. Add screenshots and app description
3. Submit for review
4. Start earning with AdMob ads
```
